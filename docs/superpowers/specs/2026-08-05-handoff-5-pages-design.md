# 하이파이 5페이지 Next.js 핸드오프 설계

2026-08-05 · 승인됨

## 목적

`food-recommend-design.pen`(Pencil MCP로만 접근)의 하이파이 화면 5장을 `food-recommend-app`(Next.js 16.3 + React 19 + Tailwind v4)으로 핸드오프한다. 디자인은 모바일(360px)만 존재하며, 구현은 태블릿·데스크톱까지 반응형으로 커버한다.

## 화면 → 라우트 매핑

| Pencil 화면 (노드 ID) | 라우트 | 탭바 |
|---|---|---|
| 00 로그인 · 구글 소셜 (`fU0Xw`) | `/login` | 없음 |
| 02 홈 · 오늘의 추천 (`IzbFD`) | `/` | 홈 |
| 05 레시피 상세 (`Z97wo`) | `/recipes/[id]` | 없음 (하단 고정 CTA "다 만들었어요") |
| 07 내 냉장고 (`HTs3W`) | `/fridge` | 냉장고 |
| 10 마이페이지 · 설정 (`WElEN`) | `/my` | 마이 |

- 홈·냉장고·마이는 `(tabs)` 라우트 그룹으로 묶어 TabBar 레이아웃 공유.
- 디자인의 StatusBar(12:45·배터리 등)는 디바이스 크롬이므로 웹에서 제외.
- 나머지 8개 화면(01 온보딩, 03, 04, 06, 08, 09, 11, 12)은 이번 범위 밖. 탭바의 "기록" 탭은 링크 비활성(현재 페이지 유지 또는 `#`).

## 반응형 규칙

- 공통 컨테이너: `max-w-[1280px] mx-auto px-4 sm:px-6 lg:px-8`. 1280px 초과분은 좌우 여백.
- **홈**: 추천 카드 그리드 2열(모바일, 디자인 그대로) → md 3열 → lg 4열. 히어로 카드는 md 이상에서 이미지 좌/내용 우 가로 분할 (유일한 레이아웃 변형).
- **냉장고**: 재료 리스트 1열 → md 2열 → lg 3열 카드 그리드. 상단 통계 3개는 전 구간 3열 유지.
- **마이**: 설정 섹션 카드 1열 → lg 2열.
- **상세**: 그리드 확장 없이 본문 `max-w-[768px]` 중앙 정렬.
- **로그인**: `max-w-[400px]` 중앙 정렬 (수직 중앙).
- TabBar: 전 브레이크포인트 하단 고정, 아이템은 중앙 정렬.

## 데이터·에셋

- 백엔드 없음. `src/data/`에 목 픽스처: 레시피 5종(홈 추천 = 상세 페이지 대상), 냉장고 재료 7종 + 곧 상해요 2종, 사용자·설정값. 디자인 속 실제 문구·수치를 그대로 사용.
- 상세 페이지는 5개 레시피 id 모두 동일 레이아웃으로 렌더. 디자인에 존재하는 「애호박 새우젓 덮밥」은 디자인 데이터 그대로, 나머지 4종은 같은 구조의 그럴듯한 목 데이터로 채움.
- 음식 사진은 .pen에서 `export_nodes`로 추출해 `public/images/`에 저장, `next/image` 사용.
- 인터랙션 범위: **정적 하이파이 + 링크만.** 홈 카드·"이걸로 만들기" → 상세, "Google로 계속하기" → 홈, 탭바 → 각 탭. 새로고침·토글·칩 선택 등 화면 내 상태 변화는 구현하지 않음(마크업상 시각 상태만 재현).

## 컴포넌트 규칙 (CLAUDE.md 디자인 SSOT)

- 기존 22종 UI 컴포넌트(`src/ui/`)와 파운데이션(`src/foundation/`, `src/styles/tokens.css`)을 그대로 재사용.
- 페이지 조합 블록(RecipeCard, IngredientRow, SettingRow 등)이 필요하면 **컴포넌트 + 콜로케이트 스토리를 먼저 추가한 후** 페이지에서 사용.
- Tailwind 클래스는 정적 리터럴만. 상태별 색은 JS 분기(기존 규칙 준수).

## 전역 변경

- `src/app/layout.tsx`: Geist → Pretendard Variable(`next/font/local`, 리포 루트의 `PretendardVariable.woff2`를 앱으로 복사), `lang="ko"`, 메타데이터 서비스명으로 교체.
- Next 16.3 주의: 구현 전 `node_modules/next/dist/docs/` 관련 가이드 확인 (AGENTS.md 경고).

## 검증

- 신규 블록 컴포넌트는 스토리 추가, 기존 Storybook vitest(66 tests) 그린 유지: `npx vitest --project storybook run`
- `npm run build` 통과.
- 실행 화면 캡처를 .pen 스크린샷과 대조(모바일 360px 기준), 태블릿·데스크톱 폭에서 그리드 확장 확인.
